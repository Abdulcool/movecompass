Set up a MoveCompass board

No coding. You need a NodeMCU ESP8266 board and a USB data cable.

1. Install from your computer

  1. Use Chrome or Edge on a desktop computer. Open this page over HTTPS (localhost also works).
  2. Connect the board by USB. Close Arduino Serial Monitor and any other serial apps.
  3. If no port appears, try another data cable, then install your board's CH340 driver or CP2102 driver.
  4. Click below, choose the board's USB port, then Install. For a fresh installation, erase the device when asked. This clears its previous WiFi and pairing.

Use Chrome or Edge on a desktop computer with USB serial support.

Open this page over HTTPS or localhost to enable USB installation.

The installer, manifest and firmware are served locally by this MoveCompass server. No external flashing service is used.

2. Connect it to your home WiFi

  1. In the staff Device settings, register the board for the patient's email. Keep the six-digit pairing code handy; it expires in 15 minutes and works once.
  2. After installation the LED blinks quickly. On a phone or computer, join WiFi MoveCompass-Setup. Stay connected even if it says “No internet”.
  3. The setup page should open. If it does not, open http://192.168.4.1 in your browser.
  4. Select your home 2.4 GHz WiFi and enter its password. Paste the server address below and the pairing code, then Save.

If pairing fails, check the address and ask staff for a new code. Rejoin MoveCompass-Setup to try again.

3. Check the connection

The LED blinks slowly while connecting and turns off when ready. The board appears Online in staff Device settings. Complete a set as its patient: the LED flashes five times, then holds for three seconds.

WiFi and pairing are remembered, so normal restarts need no setup.

To change setup later, tap RESET, release it, then immediately hold FLASH for five seconds. Do not hold FLASH during reset: GPIO0 is also the serial bootloader pin. Setup uses an open local WiFi network; configure it in a trusted place. Demo HTTPS/WSS does not verify server certificates.
